### 1. Өз алдынча окуудан чыгарылган суроолор
Өз алдынча окууда кеңири жооптуу тапшырмалар (эссе) бааланбайт.

### 2. Баалоо тутумдарының түрлөрү
Баалоо тутумдары айып упайларынын жана жарым-жартылай упайлардын болушуна жараша төрт түргө бөлүнөт.

- 2.1. **Айып упайлары жана жарым-жартылай упайлар менен баалоо тутуму:** Айып упайлары жана жарым-жартылай упайлар тесттерге гана колдонулат; кыска жооптуу тапшырмаларда жарым-жартылай упайлар берилбейт жана ката жооп үчүн айып упайлары чегерилбейт.
    + 2.1.1. **Бир жооптуу тест**
        * 2.1.1.1. Туура жооп: **Белгиленген упай** берилет.
        * 2.1.1.2. Жооп тандалбаса же эки же андан көп жооп тандалса: **0 упай** берилет.
        * 2.1.1.3. Бир туура эмес жооп тандалса: **Белгиленген упай / (варианттардын саны - 1) өлчөмүндө айып упайы** чегерилет.
    + 2.1.2. **Бир нече жооптуу тест**
        * 2.1.2.1. Тандалган жооптордун саны туура жооптордун санына дал келсе жана бардык тандалган жооптор туура болсо: **Белгиленген упай** берилет.
        * 2.1.2.2. Тандалган жооптордун саны туура жооптордун санынан айырмаланса: **0 упай** берилет.
        * 2.1.2.3. Тандалган жооптордун саны туура жооптордун санына дал келсе: **(варианттардагы туура эмес жооптордун саны x тандалган туура жооптордун саны - варианттардагы туура жооптордун саны x тандалган туура эмес жооптордун саны) x Белгиленген упай / варианттардын жалпы саны упай** берилет.
- 2.2. **Айып упайлары бар жана жарым-жартылай упайларсыз баалоо тутуму:** Айып упайлары тесттерге гана колдонулат; кыска жооптуу тапшырмаларда ката жооп үчүн айып упайлары чегерилбейт.
    + 2.2.1. **Бир жооптуу тест**
        * 2.2.1.1. Туура жооп: **Белгиленген упай** берилет.
        * 2.2.1.2. Жооп тандалбаса же эки же андан көп жооп тандалса: **0 упай** берилет.
        * 2.2.1.3. Бир туура эмес жооп тандалса: **Белгиленген упай / (варианттардын саны - 1) өлчөмүндө айып упайы** чегерилет.
    + 2.2.2. **Бир нече жооптуу тест**
        * 2.2.2.1. Тандалган жооптордун саны туура жооптордун санына дал келсе жана бардык тандалган жооптор туура болсо: **Белгиленген упай** берилет.
        * 2.2.2.2. Тандалган жооптордун саны туура жооптордун санынан айырмаланса: **0 упай** берилет.
        * 2.2.2.3. Тандалган жооптордун саны туура жооптордун санына дал келсе, бирок туура эмес жооп тандалса же туура жооптордун айрымдары калып калса: **Белгиленген упай / (варианттардын саны x (варианттардын саны - 1)) өлчөмүндө айып упайы** чегерилет.
- 2.3. **Айып упайлары жок жана жарым-жартылай упайлар менен баалоо тутуму**
    + 2.3.1. **Бир жооптуу тест**
        * 2.3.1.1. Туура жооп: **Белгиленген упай** берилет.
        * 2.3.1.2. Калган учурларда: **0 упай** берилет.
    + 2.3.2. **Бир нече жооптуу тест**
        * 2.3.2.1. Тандалган жооптордун саны туура жооптордун санына дал келсе жана бардык тандалган жооптор туура болсо: **Белгиленген упай** берилет.
        * 2.3.2.2. Тандалган жооптордун саны туура жооптордун санынан айырмаланса: **0 упай** берилет.
        * 2.3.2.3. Тандалган жооптордун саны туура жооптордун санына дал келсе: **Белгиленген упай x тандалган туура жооптордун саны / варианттардагы туура жооптордун саны упай** берилет.
- 2.4. **Айып упайларысыз жана жарым-жартылай упайларсыз баалоо тутуму**
    + 2.4.1. **Бир жооптуу тест**
        * 2.4.1.1. Туура жооп: **Белгиленген упай** берилет.
        * 2.4.1.2. Калган учурларда: **0 упай** берилет.
    + 2.4.2. **Бир нече жооптуу тест**
        * 2.4.2.1. Тандалган жооптордун саны туура жооптордун санына дал келсе жана бардык тандалган жооптор туура болсо: **Белгиленген упай** берилет.
        * 2.4.2.2. Калган учурларда: **0 упай** берилет.

### 3. Баалоо эрежелеринин жөндөөлөрүн бөлүшүү
Өз алдынча окуунун баалоо эрежелеринин жөндөөлөрү экзамен түзүүдөгү экзамендин чөйрөсүнүн жөндөөлөрү менен маанилерди бөлүшөт, ошондуктан экзамендин чөйрөсүнүн жөндөөлөрүн өзгөртүү өз алдынча окуунун баалоо эрежелеринин жөндөөлөрүн автоматтык түрдө жаңылайт.

### 4. Айып упайлары тутумунун пайдалуулугу
- 4.1. Экзамен — бул студенттин **ийгилигин (ооматын)** эмес, анын **жөндөмдүүлүгүн** баалоо куралы.
- 4.2. Экзамендерде айып упайлары тутуму студенттерге өтө катаал сезилгендиктен, иш жүзүндө көп тандалбайт. Бирок студенттин билимин так баалоого тийиш болгон баалоочунун көз карашы боюнча, айып упайлары жок болсо, студенттин **билими менен кошо анын ооматы да** бааланып калат. **Бул так баалоого тоскоол болгон «ызы-чуу» (ноиз) сыяктуу ролду ойнойт.** Ошондуктан, айып упайлары жок баалоодо тактык төмөндөйт. Мисалы, 40 суроодон турган төрт варианттуу тестте студент эч нерсе билбей туруп бардык суроолорду белгилеп чыкса, болжол менен 30 суроодон жаңылып, 10 суроого туура жооп бериши мүмкүн. **Эч нерсе билбесе да, 25% туура жооп берет дегендик.** Эч нерсе билбеген студент 0 упай алышы керек болсо, бул жерде 25 упай алып калган **баалоо ызы-чуусу** пайда болот.
- 4.3. **Тиешелүү өлчөмдөгү айып упайы мындай оомат менен алынган упайларды толугу менен болбосо да, кыйла деңгээлде жокко чыгарат.** Дагы бир мисал: 40 суроодон турган төрт варианттуу тестте эч нерсе билбеген студент бардык суроолорду белгилесе, болжол менен 10 суроо туура, 30 суроо ката болот. Төрт варианттуу тестте туура табуу ыктымалдыгы 1/4 (25%), ал эми жаңылбоо ыктымалдыгы 3/4 (75%). Эгер туура жооп үчүн 2,5 упай берилип, ката жооп үчүн 0,83 упай (= 2,5 / 3) алынса, эч нерсе билбеген студенттин упайы **0гө жакын болот**. Эч нерсе билбеген студенттин 0 упай алышы туура. Эгер упай минус болуп кетсе, терс упай берилбейт, 0 упай деп эсептелет.
- 4.4. Айып упайлары тутуму студент төрт варианттын ичинен бирөө туура эмес экенин так билип, калган үчөөнүн бирин тандаган учурда да, **анын ошол жарым-жартылай билимин автоматтык түрдө баалайт**. Мисалы, 40 суроодон турган тестте студент бир варианттын туура эмес экенин билип, калган үчөөнүн бирин белгилесе, болжол менен 13 суроо туура, 27 суроо ката болот. Үч варианттуу учурда туура табуу ыктымалдыгы 1/3 (33,3%), ал эми жаңылуу ыктымалдыгы 2/3 (66,7%). Туура жооп үчүн 2,5 упай берилип, ката үчүн 0,83 упай алынса, мындай студенттин упайы болжол менен 11,2 упайга жетет. **Туура жоопту билбесе да, «бул жооп эмес» экенин түшүнгөн студенттин билими 11,2 упай менен бааланат.**
- 4.5. Буга чейинки айтылгандар статистикадагы **чоң сандардын мыйзамына** негизделген. Көпчүлүк учурда студенттер өтө көп суроону туш келди белгилебегендиктен, **чоң сандардын мыйзамын колдонууга болбойт**. Бирок, мындай учурларда студенттер — төрт варианттуу тестти мисалга алсак — туш келди белгилөө менен 3 упай алуу ыктымалдыгына караганда 1 упай жоготуу ыктымалдыгы үч эсе жогору экенин түшүнүп, **жооп бербөө стратегиясын тандашат**. Бул студенттин өзү тарабынан баалоодогу «ызы-чууну» (ноизди) жокко чыгарууга алып келет. Статистикалык жактан алганда, жооп бербөө 100% ыктымалдык менен 0 упай берет, ал эми туш келди белгилөөдө күтүлгөн маани 0 болгону менен, стандарттык четтөө 0дөн чоң болот. Демек, **туш келди белгилөө стратегиясы акылдуулукка жатпайт**.
