### 1. .qbdb <-> .qb.xlsx
Учурдагы qbdb файл форматы xlsx файл форматына которулуп, qbdb файлындагы маалыматтарды Excel'де түзөтүүгө мүмкүнчүлүк берилди. Excel'де түзөтүү аяктагандан кийин, ал кайра qbdb файл форматына которулуп, QuizWiz'де колдонууга ылайыкташтырылды. QuizWiz суроолор банкын түзөтүү үчүн сонун мүмкүнчүлүктөрдү бергени менен, кээде Excel'де түзөтүү ыңгайлуураак болот.

### 2. .sbdb <-> .sb.xlsx
Учурдагы sbdb файл форматы xlsx файл форматына которулуп, sbdb файлындагы маалыматтарды Excel'де түзөтүүгө мүмкүнчүлүк берилди. Excel'де түзөтүү аяктагандан кийин, ал кайра sbdb файл форматына которулуп, QuizWiz'де колдонууга ылайыкташтырылды. QuizWiz студенттердин тизмесин түзөтүү үчүн сонун мүмкүнчүлүктөрдү бергени менен, кээде Excel'де түзөтүү ыңгайлуураак болот.
