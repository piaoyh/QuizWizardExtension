### 1. .qbdb <-> .qb.xlsx
Существующий формат файла qbdb был преобразован в формат файла xlsx, чтобы данные из файла qbdb можно было редактировать в Excel. После завершения редактирования в Excel файлы снова преобразуются в формат qbdb для использования в QuizWiz. Хотя QuizWiz предоставляет отличные функции для редактирования банка вопросов, иногда удобнее редактировать их в Excel.

После завершения редактирования в Excel файлы снова преобразуются в формат sbdb для использования в QuizWiz. Хотя QuizWiz предоставляет отличные функции для редактирования списка студентов, иногда удобнее редактировать их в Excel.
