### 1. .qbdb <-> .qb.xlsx
The existing qbdb file format has been converted to the xlsx file format so that the data in the qbdb file can be edited in Excel. Once editing in Excel is complete, it is converted back to the qbdb file format so it can be used in QuizWiz. Although QuizWiz provides great features for editing question banks, it is sometimes more convenient to edit in Excel.

### 2. .sbdb <-> .sb.xlsx
The existing sbdb file format has been converted to the xlsx file format so that the data in the sbdb file can be edited in Excel. Once editing in Excel is complete, it is converted back to the sbdb file format so it can be used in QuizWiz. Although QuizWiz provides great features for editing student rosters, it is sometimes more convenient to edit in Excel.
