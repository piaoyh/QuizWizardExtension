### 1. Theme
Currently, QuizWiz's interface theme offers three options: **Blue Theme**, **Light Theme**, and **Calm Theme**. **Blue Theme** is set as the default.

### 2. Font
This is the font for the QuizWiz interface. It searches for fonts installed on the operating system and allows you to select one among them. This is not the font required when printing questions on paper.

### 3. Language
Currently, **Korean**, **English**, **Russian**, and **Kyrgyz** are supported. The advantage is that you can set the language of QuizWiz independently of the operating system's language.
