# QuizWiz Quick Start
QuizWiz is a Chrome extension that helps with efficient question bank management, exam creation, student list management, and self-directed learning.

After installing this extension in your Chrome browser, you can launch the app using ctrl+shift+, or ⌘+shift+,. The reason for using a comma (,) as the shortcut is that in Korean, a comma signifies a 'resting mark.' It is a gentle reminder not to just work hard constantly, but to take breaks and work at a leisurely pace.

### 1. Question Bank
You can manage exam questions directly in the Question Bank workspace.

- 1.1. **New/Open/Save:** Manage question bank files.
- 1.2. **Edit:** Modify question text and choices. Add with '+' or remove with '-' buttons.
- 1.3. **Toggle:** Switch between question and choice editing modes.

### 2. Exam Setting
Create personalized exam papers based on the prepared question bank and student list.

- 2.1. **Set Scope:** Specify the range of question numbers and the number of questions.
- 2.2. **Save Exam Paper:** Save personalized exam papers for each student.

### 3. Student List
Manage examinee information.

- 3.1. **Add/Remove:** Add students to the list or select them to remove.
- 3.2. **Optimize:** Clean up empty fields in student information.

### 4. Self-Study
Set the study scope and take mock exams.

- **Scoring Rules:** Decide on penalty policies and partial credit.

### 5. 도구
You can use various useful features.

- 5.1. **.qbdb -> .qb.xlsx:** Converts a qbdb file to Excel format.
- 5.2. **.qb.xlsx -> .qbdb:** Converts a question bank in Excel format to qbdb format.
- 5.3. **.sbdb -> .sb.xlsx:** Converts an sbdb file to Excel format.
- 5.4. **.sb.xlsx -> .sbdb:** Converts a student list in Excel format to sbdb format.


### 6. Settings
Adjust app environment settings to your preference.

- 6.1. **Theme:** Select between Blue, Light, and Dark themes.
- 6.2. **Font:** Change to your preferred font.
- 6.3. **Language:** Choose between Korean, English, Russian, and Kyrgyz.
- 6.4. **Default Number of Choices:** Select the default number of choices for multiple-choice questions.
