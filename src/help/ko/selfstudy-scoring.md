### 1. 자기 주도 학습에서 배제되는 문제
자기 주도 학습에서는 논술형 주관식 문제를 채점하지 않는다.

### 2. 채점 방식의 종류
채점 방식에는 감점 여부와 부분 점수 여부에 따라 4가지로 나눌 수 있다.

- 2.1. **감점이 있고 부분 점수가 있는 채점 방식:** 감점과 부분 점수는 객관식 문제에만 적용되며, 단답형 주관식 문제는 부분 점수가 없고 틀려도 감점되지 않는다.
    + 2.1.1. **단일 선택형 객관식**
        * 2.1.1.1. 정답을 맞힌 경우: **배정된 점수**가 부여된다.
        * 2.1.1.2. 답을 선택하지 않거나 두 개 이상의 답을 선택한 경우: **0점**이 부여된다.
        * 2.1.1.3. 하나의 오답을 택한 경우: **배정된 점수 / (선택지의 개수 - 1)의 감점**을 부여받는다.
    + 2.1.2. **복수 응답형 객관식**
        * 2.1.2.1. 선택한 답의 개수가 정답의 개수와 같고 선택한 모든 답이 정답인 경우: **배정된 점수**가 부여된다.
        * 2.1.2.2. 선택한 답의 개수가 정답의 개수와 다른 경우: **0점**이 부여된다.
        * 2.1.2.3. 선택한 답의 개수가 정답의 개수와 같은 경우: **(선택지에서의 오답의 개수 x 선택한 정답의 개수 - 선택지에서의 정답의 개수 x 선택한 오답의 개수) x 배정된 점수 / 선택지의 개수 점**이 부여된다.
- 2.2. **감점이 있고 부분 점수가 없는 채점 방식:** 감점은 객관식 문제에만 적용되며, 단답형 주관식 문제는 틀려도 감점되지 않는다.
    + 2.2.1. **단일 선택형 객관식**
        * 2.2.1.1. 정답을 맞힌 경우: **배정된 점수**가 부여된다.
        * 2.2.1.2. 답을 선택하지 않거나 두 개 이상의 답을 선택한 경우: **0점**을 부여받는다.
        * 2.2.1.3. 하나의 오답을 택한 경우: **배정된 점수 / (선택지의 개수 - 1)의 감점**을 부여받는다.
    + 2.2.2. **복수 응답형 객관식**
        * 2.2.2.1. 선택한 답의 개수가 정답의 개수와 같고 선택한 모든 답이 정답인 경우: **배정된 점수**가 부여된다.
        * 2.2.2.2. 선택한 답의 개수가 정답의 개수와 다른 경우: **0점**을 부여받는다.
        * 2.2.2.3. 선택한 답의 개수가 정답의 개수와 같고 오답을 포함하거나 정답 중 일부를 누락할 경우: **배정된 점수 / (선택지의 개수 x (선택지의 개수 - 1))의 감점**을 부여받는다.
- 2.3. **감점이 없고 부분 점수가 있는 채점 방식**
    + 2.3.1. **단일 선택형 객관식**
        * 2.3.1.1. 정답을 맞힌 경우: **배정된 점수**가 부여된다.
        * 2.3.1.2. 그 외의 경우: **0점**을 부여받는다.
    + 2.3.2. **복수 응답형 객관식**
        * 2.3.2.1. 선택한 답의 개수가 정답의 개수와 같고 선택한 모든 답이 정답인 경우: **배정된 점수**가 부여된다.
        * 2.3.2.2. 선택한 답의 개수가 정답의 개수와 다른 경우: **0점**을 부여받는다.
        * 2.3.2.3. 선택한 답의 개수가 정답의 개수와 같은 경우: **배정된 점수 x 선택한 정답의 개수 / 선택지에서의 정답의 개수 점**이 부여된다.
- 2.4. **감점이 있고 부분 점수가 없는 채점 방식**
    + 2.4.1. **단일 선택형 객관식**
        * 2.4.1.1. 정답을 맞힌 경우: **배정된 점수**가 부여된다.
        * 2.4.1.2. 그 외의 경우: **0점**을 부여받는다.
    + 2.4.2. **복수 응답형 객관식**
        * 2.4.2.1. 선택한 답의 개수가 정답의 개수와 같고 선택한 모든 답이 정답인 경우: **배정된 점수**가 부여된다.
        * 2.4.2.2. 그 외의 경우: **0점**을 부여받는다.
### 3. 채점 방식의 설정 공유
자기 주도 학습의 채점 방식 설정은 시험 문제 출제의 출제 범위 설정과 설정 값을 공유하므로 시험 문제 출제의 출제 범위 설정을 고치면 자동으로 자기 주도 학습의 채점 방식 설정도 바뀐다.

### 4. 감점 제도의 유용성
- 4.1. 시험은 학생들의 **실력를 평가하는 도구**이지 학생들의 **운을 평가하는 도구**가 아니다.
- 4.2. 시험에서 감점 제도는 학성들에게 지나치게 가혹하다는 인상을 주기 때문에 현실에서는 잘 선택하지 않는 것이 일반적이다. 하지만, 학생들의 실력을 엄밀하게 평가해야 하는 상황에 처한 평가자의 입장에서는, 학생의 실력을 평가함에 엤어서, 개별 학생들의 **실력과 함께 운까지** 함께 평가하게 되어, **운에 의한 점수가 정확한 평가를 방해하는 일종의 노이즈로서 역할을 하게 된다.** 따라서, 감점 제도가 없는 평가에는 평가의 정확성이 떨어지는 맹점이 있다. 극단적인 예를 들어, 사지선다형 40문제로 된 시험이 있고 한 학생이 아무것도 모르는데 모든 문제를 찍으면 대략 30문제 내외로는 틀리고 10문제 내외로는 맞힐 것으로 예상할 수 있다. **아무것도 모르면서 정답륩 25%를 기록하게 되는 것이다.** 아무것도 모른다면 0점을 받아야 할 학생이 25점이나 받는 **평가의 노이즈**가 있는 것이다.
- 4.3. **적절한 크기의 감점은 이러한 운에 의한 노이즈를 완벽하게는 아닐지라도 유의미한 정도로 상쇄시켜 준다.** 다시 극단적인 예를 들어 사지선다형 40문제로 된 시험이 있고 한 학생이 아무것도 모르는데 모든 문제를 찍으면 대략 30문제 내외로는 틀리고 10문제 내외로는 맞힐 것으로 예상할 수 있다. 이는 사지선다형의 경우 답을 찍어서 맞힐 확률이 1/4 (= 25%)이고, 찍어서 틀릴 확률은 3/4 (= 75%)이기 때문이다. 그래서 답을 맞히면 배정된 점수인 2.5점을 받고 답을 맞히지 못하면 0.83점 (= 2.5 / 3)을 잃는다면 아무것도 모르는 학생이 40문제를 찍는다면 **거의 0점에 수렴할 것이다.** 아무것도 모르는 학생이 0점을 받는 것은 당연하다. 점수가 음수가 나온다면 음의 점수는 없으므로 0점을 준다.
- 4.4. 감점 제도는 학생이 어설프게 알아서 4개의 선택지들 중에서 하나는 답이 아니라는 것을 확실히 알고 남은 3개 중의 하나를 찍는 경우에도 **학생이 어설프게 아는 그 부분도 자동으로 평가해 준다.** 다시 극단적인 예를 들어 사지선다형 40문제로 된 시험이 있고 한 학생이 어설프게 아는데 모든 문제를 선택지 하나는 답이 아니라는 것을 확실하게 알므로 선택지 세 개 중에서 하나를 찍으면 대략 27문제 내외로는 틀리고 13문제 내외로는 맞힐 것으로 예상할 수 있다. 이는 삼지선다형의 경우 답을 찍어서 맞힐 확률이 1/3 (= 33.3%)이고, 찍어서 틀릴 확률은 2/3 (= 66.7%)이기 때문이다. 그래서 답을 맞히면 배정된 점수인 2.5점을 받고 답을 맞히지 못하면 0.83점 (= 2.5 / 3)을 잃는다면 어설프게 아는 학생이 40문제를 찍는다면 거의 11.2점에 수렴할 것이다. **정답이 뭔지는 몰라도 이건 답이 아니다라는 것을 어설프게 아는 학생의 실력은 11.2점으로 계산되는 것이다.**
- 4.5. 지금까지는 통계학의 **대수의 법칙**을 적용할 때의 이야기이고, 많은 경우에는 학생들이 찍는 문제가 많지 않으므로 **대수의 법칙을 적용할 수 없다.** 하지만, 그러한 경우에 학생들은, 사지선다형의 문제를 예로 들면, 찍어서 3점을 얻을 확률보다 1점을 잃을 확률이 세 배 더 높으므로 **답을 쓰지 않는 전략을 선택한다.** 이는 학생 스스로 평가의 노이즈를 배제하는 결과를 낳는다. 통계학적으로도, 답을 쓰지 않으면 100% 확률로 0점을 얻지만, 답을 찍으면 기대값은 0점인데 얻게 될 점수의 표준편차는 0보다 큰 값이므로, **찍는 전략은 결코 지혜로운 선택이 아니다.**
