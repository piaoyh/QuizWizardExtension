# QuizWiz 시작하기
QuizWiz는 효율적인 문제 은행 관리, 시험지 출제, 학생 명단 관리 및 자기 주도 학습을 돕는 크롬 확장앱입니다.

본 확장 앱을 크롬 브라우저에 설치한 후에는 크롬 브라우저에서 ctrl+shift+, 또는 ⌘+shift+,로 본 앱을 실행시킬 수 있습니다. 단축키로 ,(쉼표)를 사용한 이유는 한국어에서 쉼표는 '쉬는 표시'라는 뜻입니다. 열심히 일만 하지 마시고 쉬엄쉬엄 일하시라는 뜻입니다.

### 1. 문제 은행
문제 은행 작업공간에서는 시험 문제를 직접 관리할 수 있습니다.

- 1.1. **새로 만들기/열기/저장:** 문제 은행 파일을 관리합니다.
- 1.2. **편집:** 각 문제의 텍스트와 객관식 선택지를 수정할 수 있습니다. + 버튼으로 추가하고 - 버튼으로 삭제합니다.
- 1.3. **토글:** 문제 편집 모드와 선택지 편집 모드를 전환합니다.

### 2. 시험 문제 출제
준비된 문제 은행과 학생 명단을 바탕으로 맞춤형 시험지를 생성합니다.

- 2.1. **학습 범위 설정:** 출제할 문제 번호 범위와 문항 수를 지정합니다.
- 2.2. **시험지 저장:** 학생별로 다르게 출제된 시험지를 PDF 등으로 저장할 수 있습니다.

### 3. 학생 명단
수험생 정보를 관리합니다.

- 3.1. **학생 추가/제외:** 리스트에 학생을 추가하거나 선택하여 삭제합니다.
- 3.2. **최적화:** 학생 정보 중 빈 칸이 있는 경우 깔끔하게 정리합니다.

### 4. 자기 주도 학습
출제 범위를 설정하고 직접 모의 시험을 치를 수 있습니다.

- **채점 방식 설정:** 감점 정책과 부분 점수 여부를 결정합니다.

### 5. 도구
유용한 기능들을 사용할 수 있습니다.

- 5.1. **.qbdb -> .qb.xlsx:** qbdb 파일을 엑셀 포맷으로 변환합니다.
- 5.2. **.qb.xlsx -> .qbdb:** 엑셀 포맷으로 된 문제 은행을 qbdb 포맷으로 변환합니다.
- 5.1. **.sbdb -> .sb.xlsx:** 엑셀 포맷으로 된 학생 명단을 sbdb 포맷으로 변환합니다.
- 5.1. **.sb.xlsx -> .sbdb:** sbdb 파일을 엑셀 포맷으로 변환합니다.


### 6. 설정
앱의 환경을 개인 취향에 맞게 조정합니다.

- 6.1. **테마:** Blue, Light, Dark 테마 중 선택 가능합니다.
- 6.2. **글꼴:** 선호하는 폰트로 변경할 수 있습니다.
- 6.3. **언어:** 한국어, English, Русский, Кыргызча 중에서 선택합니다.
- 6.4. **선택지 기본 개수:** 다지선다형에서 선택지의 기본 개수를 선택합니다.

### 7. 정보
앱의 버전, 저작권, 라이센스, 사용된 기술 스택(Rust, Wasm, TypeScript 등)을 확인할 수 있습니다.
